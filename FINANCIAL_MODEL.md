## Sensitivity Analysis

### What if commodity prices spike 20%?

```
FCI model (locked escalation):
  Year 1 commodity cost: ₹8–10/kg
  With 20% spike: ₹9.6–12/kg
  Escalation clause: CPI + 1.8% max
  Additional cost: ₹0.2–0.4/kg (~2% of budget)
  
Result: Minimal impact; locked contract protects against inflation
```

### What if private vendors cut prices 15%?

```
Private vendor model (best case):
  Current ₹71/unit → ₹60/unit (15% cut)
  But: Unsustainable (vendors lose margin)
  Historical pattern: Cuts last 1–2 years, then 10–15% hikes follow
  
FCI model: Immune to price wars (govt-to-govt pricing, stable)
Long-term: FCI remains cheaper even if private discounts occur
```

### What if FCI mill breaks down?

```
Risk mitigation:
  1. 20 FCI mills nationwide (distributed redundancy)
  2. Any 1-2 mill outage → others absorb capacity
  3. Lead time for switch: 2–3 weeks (not critical)
  4. OFB backup: Can shift some production to state mills or NAFED
  
Result: Zero supply gap (vs 30-day gap if private vendor fails)
```

## ROI Calculation

```
Setup investment: ₹2.85 Cr

Net profit (5 years): ₹7.12 - ₹2.85 = ₹4.27 Cr

ROI % = (Net profit / Initial investment) × 100
```
