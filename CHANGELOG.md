# Changelog: Jai Kisan, Jai Javan

All notable changes to this FCI-based military RTC strategy document are recorded here.

## [1.0.0] — 2026-07-31 (Initial Release)

### Added
- **STRATEGY.md** — Core 12-month implementation roadmap (strategy + vision)
- **SOURCING_CHANNELS.md** — Multi-channel sourcing (FCI, state boards, APMC, NAFED, FPOs)
- **FINANCIAL_MODEL.md** — 5-year cost projections, ROI analysis, farmer impact
- **CABINET_SUBMISSION_BRIEF.md** — Executive summary for Cabinet approval
- **README.md** — Complete repository structure + quick-start guide
- **LICENSE** — MIT license (public domain for government implementation)

### Key Metrics (v1.0)
- Unit cost reduction: 62% (₹71 → ₹27)
- 5-year savings: ₹6.4 Cr (net)
- Annual farmer income support: ₹251 Cr (50,000 farmers)
- Jobs created: 54,700 (direct + indirect)
- Implementation timeline: 18 months

### Strategic Goals (v1.0)
- ✅ Supply autonomy (100% domestic sourcing)
- ✅ Soldier welfare (region-adapted, nutrition-optimized)
- ✅ Farmer support (₹250–300 Cr annual procurement)
- ✅ Multi-channel resilience (FCI + state + APMC + cooperative + FPO)
